# web/src/pages/how-it-works/

**职责**:面向面试官的**项目说明页**(讲设计思想与架构,不是使用手册),**图先于字**、自读优先、投屏靠 Expand all。零后端依赖。
计划见 `documents/HOW-IT-WORKS-PLAN.md`(v2 在 §10,v2.1 并回总页在 §11,v3 自读优先重排在 §12,v4 图先于字在 §13,**v5 层级纠正 + 第四种知识在 §14**)。

**层级口径(v5,2026-08-27 需求方纠正,全站以此为准)**:精准问答 / 智能问数 / **编排(workflow)**
三者**同级** —— 都事先注册意图,回答时一次意图匹配、谁命中谁执行(同级之间只有「谁更具体」的
tie-break);**文档 RAG 是兜底**,只在没有任何意图命中时才跑,再往下才是「说没有依据」。
编排是第四种知识:**不产生新事实**,只把前三种按签过字的顺序连起来,外加代码节点与动作节点。
它目前**只有设计,没有后端**(导航里的占位页在 `src/domains/workflow/`),
但在说明页里**和三层一样有自己的一页**(`/how-it-works/workflow`),侧栏四页并列。
