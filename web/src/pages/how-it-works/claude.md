# web/src/pages/how-it-works/

**职责**:面向面试官的**项目说明页**(讲设计思想与架构,不是使用手册),**图先于字**、自读优先、投屏靠 Expand all。零后端依赖。
计划见 `documents/HOW-IT-WORKS-PLAN.md`(v2 在 §10,v2.1 并回总页在 §11,v3 自读优先重排在 §12,**v4 图先于字在 §13**)。

| 文件               | 说明                                                                                                                                                                                                                                                               |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `content.ts`       | **文案唯一出处**:主张 / **全局图 `SYSTEM_MAP`** / 路由漏斗(带标题与例句)/ 三层(带 `freedom` 自由度)/ 四条立场 / 痛点 / 治理骨架 / 三层对比 / 取舍;架构段六小节(六层技术架构含供应商接缝 / 外壳内核 / 一次请求 / 闭环含 `phase` / 四层评估 / 自主性边界),折叠摘要一律结论句;页脚署名 `AUTHORS`;三个子页(含每层两条流程);**侧栏子项清单 `HOW_IT_WORKS_NAV`** |
| `figures.tsx`      | 全部图形,纯填充块 + lucide 箭头,无图表库。**画法纪律:每张图都看得见方向** —— 步骤间一律有箭头(`FlowArrow`)、分岔左右分开、闭环有虚线回边。含 `SystemMapFigure`(全局图)/ 倒漏斗 / `FreedomMeter` / 请求判定流程图 / 技术架构(接缝)/ 外壳内核 / 治理骨架(带箭头)/ 角色闭环(两行 + 回边)/ 四层评估链 / 自主性边界(中间一道线)/ 子页流程 |
| `Section.tsx`      | 排版元件;**UI-STYLE 演示页字阶的唯一落地处**(24px 以上 sans 只许出现在这里);`CollapsibleScreen` 支持受控(open/onToggle)与非受控两用                                                                                                                                |
| `OverviewPage.tsx` | 总页 `/how-it-works`(图先于字):主张 + **全局图** → 路由漏斗(例句)+ R1–R3 → 三层卡片(例子 chips + 自由度条)→ 一次请求(判定流程图)→ 架构段(四条立场常驻 + 五小节折叠)→ 四折叠区 → 署名;9 个折叠区共用 Expand all / Collapse all |
| `LayerPage.tsx`    | 子页 `/how-it-works/:layer`:主角句 + 示例 → 治理/回答两条流程 → 四张关键词卡 → may/may not                                                                                                                                                                         |
| `index.ts`         | 对外只导出两个页面组件 + `HOW_IT_WORKS_NAV`(给 AppLayout 摆侧栏)                                                                                                                                                                                                   |
