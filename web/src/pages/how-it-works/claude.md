计划见 `documents/HOW-IT-WORKS-PLAN.md`(v2 在 §10,v2.1 并回总页在 §11,v3 自读优先重排在 §12)。

| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `content.ts`       | **文案唯一出处**:主张(漏斗含例句)/ 四条立场 / 痛点 / 治理骨架 / 三层对比 / 取舍;架构段六小节(六层技术架构 / 外壳内核 / 一次请求 / 闭环 / 四层评估 / 自主性边界),折叠摘要一律结论句;页脚署名 `AUTHORS`;三个子页(含每层两条流程);**侧栏子项清单 `HOW_IT_WORKS_NAV`** |
| `figures.tsx`      | 全部图形(倒漏斗——每层带例句行、治理骨架、技术架构、外壳内核、请求链路、角色闭环、评估、自主性边界、子页流程),纯填充块,无图表库                                                                                                                                     |
| `Section.tsx`      | 排版元件;**UI-STYLE 演示页字阶的唯一落地处**(24px 以上 sans 只许出现在这里);`CollapsibleScreen` 支持受控(open/onToggle)与非受控两用                                                                                                                                |
