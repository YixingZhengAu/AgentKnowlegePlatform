# web/src/domains/text2sql/

**职责**:智能问数(text2sql)域前端 —— 数据源接入、语义层治理、意图与模板、chat 展示,
一切代码都落在这里。当前 D1–D5 全部完成并自测(数据源 / Schema 治理 / 意图列表与候选审核 /
意图详情 / chat 展示)。

| 文件 | 说明 |
| --- | --- |

| `IngestPage.tsx` | 域内路由壳(`/ingest/text2sql/*` 的二级页在这里摆) |
| `DatasourcesPage.tsx` | D1 首页:新建连接(**唯一收口令的地方**)+ 测连 + 列表 + 同步 + 治理进度 |

**四个必须记住的设计点**(展开在 `architect.md`):

1. **先测再存**:表单里的测连打不落库的那个接口,填错口令不会在库里留下连不上的数据源。
2. **口令进不出**:存完再也拿不回来(后端只回 host/port/user/database)。
3. **按表保存**:治理草稿留在前端,Save 一次事务;**左侧的启用开关是例外 —— 它立即落库**。
4. **AI 只给建议**(单点):同步返回、填进草稿,人看过再 Save;批量走 Job **直接写库**。
   单列的 AI 按钮也是整表生成(评审过的 prompt 是表级的),只回填那一格。
   **`fill` 保住的是库里的 DDL 注释,不是人在页面上打的字** —— 提示语按模式给两句话。

**D4 的三个要点**:一张卡片一次保存(四块内容打四个不同的后端动作,没有"全保存");
**Run 打的是运行时那道执行闸**,被闸拒是 200 + `ok=false`(界面上就该看见"闸说了什么");
参数区重解析读的是**库里那条 SQL**,所以编辑器有未保存改动时按钮变灰。
生成器的设计说明(join 路径 / 度量口径 / **写死的过滤及其理由**)是评审材料,原样摆在 SQL 下面。

**D3 的两个要点**:候选审核复用泛型审核台(本域只给渲染器 + 动作层),
生成走 Job 且**追加安全**(已有摘要喂回 prompt 避重);空路由负例面是 kb 级资产,
所以摆在意图列表页而不是某个意图下(Agent 设置页属 shared 层,不往里塞本域资产)。

**D5 的三个要点**:结果表格默认摊开(结论那句话是代码从它算出来的,先让人看见数),
最终 SQL 折叠 + 复制,**复制到的就是执行过的原文**(高亮只加 span,不动一个字符);
`needs_confirmation` 要说出来 —— 踩线过的命中会在引用里写明"下一名分数几乎一样"。
数据全在 `citation.extra` 里,**前端不为了画这张表再发一次请求**(那条 SQL 再跑未必是同一份数)。

详见 `architect.md`;跨域约定见 `../claude.md`。
