# S3 实验床评审记录(B1–B8)

S3 智能问数的准确率逻辑不是直接写进正式代码库的:先在开发机上的一个独立实验床
(当时在 `tmp/s3-dev/`,**从未入库**)里逐段实测调优,每段产出一份评审报告给人工过闸,
关闸后才把逻辑原样平移到 `server/app/services/text2sql/`。

**这个目录就是那 9 份评审报告的存档**,是一次性真调 LLM 跑出来的证据,删了不可复现。
2026-08-24 清理实验床(44 MB)时把它们捞了出来,其余产物(独立 venv、embedding 缓存、
llm_log、中间 JSON)全部删除。
