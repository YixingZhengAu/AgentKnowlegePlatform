# 前端风格规范(UI-STYLE)

**基准**:https://www.clenergy.com.au/ 官网视觉语言(2026-08 抓取分析)。
**约束力**:Step 6 起所有前端开发遵循本文档;shadcn/ui 主题变量、Tailwind token 以此为唯一来源。改风格先改这里。

## 0. 官网视觉基因(分析结论)

对官网 HTML/CSS 的统计分析结果:

- **主色是深海军蓝 `#00205B`**,全站出现 300+ 次,用于标题、导航、主按钮、页脚——品牌的绝对核心
- **亮黄 `#FFCB02` 是唯一强调色**,用量极克制(仅 CTA 和高亮),橙 `#F28601` 偶尔做辅助
- 大面积**白底 + 浅灰分区**(`#FAFAFA` / `#F7F7F7`),边框浅灰 `#D5D5D5`
- 正文深灰 `#1C1C1C` / `#474747`,次要文字 `#979797`
- 字体 **BwModelica**(几何无衬线,现代、硬朗),标题全用 Bold
- 圆角克制:按钮/输入 4–5px,卡片最大 15px;**没有大圆角、没有渐变、没有玻璃拟态**
- 整体气质:工业、可信、干净、大留白——To B 企业感,不是消费级软件的活泼感

## 1. 设计原则(四条,做任何界面前先过一遍)

1. **Navy 是身份,黄色是手指**:导航、标题、主按钮用海军蓝;黄色只用来指出"此刻该看/该点这里"(主 CTA、命中高亮、关键徽标),一屏最多一处大面积黄
2. **白卡片浮在浅灰底上**:页面底 `#F7F7F7`,内容装在白色卡片里,靠 1px 边框 + 极轻阴影分层,不靠重阴影
3. **留白即质感**:宁可信息密度低一点,也不挤;区块间距 24px 起步
4. **克制的圆角与动效**:圆角 6px(卡片 12px),动效只做 150–200ms 的 ease 过渡,不做弹跳/视差

## 2. 设计 Token(Tailwind / CSS 变量唯一来源)

### 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `primary` | `#00205B` | 品牌主色:导航底、主按钮、标题、激活态 |
| `primary-hover` | `#18206D` | 主按钮 hover(官网同款) |
| `primary-light` | `#E8EDF7` | 主色 8% 浅底:选中行、激活标签底色 |
| `accent` | `#FFCB02` | 强调:主 CTA、精准命中徽标、评分高亮;**上面永远配 navy 文字,不配白字** |
| `accent-orange` | `#F28601` | 次强调:警告类徽标,少用 |
| `bg-page` | `#F7F7F7` | 页面底色 |
| `bg-card` | `#FFFFFF` | 卡片/面板 |
| `border` | `#E4E4E7` | 常规边框(比官网 #D5D5D5 再轻半档,大量表格场景更透气) |
| `text-primary` | `#1C1C1C` | 正文 |
| `text-secondary` | `#474747` | 次级正文 |
| `text-muted` | `#979797` | 辅助说明、占位符 |
| `success` | `#3D8B37` | 成功/通过(审核"通过"、评测 pass) |
| `danger` | `#C4320A` | 失败/驳回/删除 |
| `info` | `#1C64F2` | 链接、信息态(官网蓝) |

**语义色使用规则**:审核台 通过=success、驳回=danger、待审=muted、已修改=info;trace 阶段 ok=success、error=danger;三类知识固定识别色——精准QA=`accent`(黄)、文档RAG=`info`(蓝)、智能问数=`#7C3AED`(紫),全站一致(路由徽标、KB 卡片、引用标记都用这套)。

### 字体

官网用商业字体 BwModelica,不可用,选最接近的 Google Fonts 替代。界面为英文单语(D5),字体栈按英文优化:

| 用途 | 字体栈 |
| --- | --- |
| 标题/导航/按钮 | `Montserrat, system-ui, sans-serif`(几何感最接近 BwModelica),标题一律 600–700 |
| 正文 | `Inter, -apple-system, system-ui, sans-serif` |
| 代码/SQL/trace | `'JetBrains Mono', ui-monospace, monospace` |

字号阶梯:页面标题 20px/600、卡片标题 16px/600、正文 14px、辅助 12px。**不用 24px 以上字号**(工作台不是营销页)。

### 圆角 / 阴影 / 间距

| Token | 值 |
| --- | --- |
| 圆角 | 按钮/输入/徽标 `6px`;卡片/弹窗 `12px`;不出现全圆 pill(徽标除外,徽标可 pill) |
| 阴影 | 卡片 `0 1px 3px rgb(0 32 91 / 0.06)`;弹层 `0 8px 24px rgb(0 32 91 / 0.12)`;仅此两档 |
| 间距 | 4px 基数;卡片内边距 20–24px;区块间 24px;表单行间 16px |

## 3. 布局与核心组件规则

### 三栏布局(Step 6)

- **左侧导航:navy `#00205B` 深底 + 白字**(呼应官网导航),宽 220px;激活项左侧 3px 黄色竖条 + `rgba(255,255,255,0.08)` 底;图标用 lucide-react 线性图标
- 顶栏:白底,只放当前页标题 + 面包屑 + 右侧全局动作,高 56px
- 中间内容区:`bg-page` 底,内容卡片化
- 右侧执行轨迹面板:白底,可折叠,默认宽 360px

### 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | navy 底白字,hover→`primary-hover` |
| 强调 CTA(每页至多一个,如"发布") | 黄底 `accent` + navy 文字 700 |
| 次按钮 | 白底 + 1px border + `text-secondary` |
| 危险 | 白底红字红框,确认弹窗后执行 |

### 工作台组件

- **对话气泡**:用户消息 navy 底白字右对齐;助手消息白卡片左对齐;引用标 `[1]` 用知识类型识别色的小徽标,hover 弹出摘录
- **trace 面板**:每个 stage 一行卡片——阶段名(mono 字体)+ 状态点(成功绿/失败红)+ 耗时/token 右对齐 muted;展开显示 input/output JSON(mono, 12px)
- **审核台**:列表行高紧凑(48px),置信度用 12px 徽标(≥0.9 绿 / 0.75–0.9 黄 / <0.75 红);键盘选中行用 `primary-light` 底 + 左侧 navy 竖条;批量操作栏吸底
- **进度条**:navy 主色填充;分步日志 mono 字体;失败步骤红色标注 + "从此步重跑"按钮
- **空状态**:一个线性图标 + 一句话 + 一个主按钮,不放插画

### 表格与表单

- 表格:表头 `bg-page` 底 12px/600 muted 大写间距,行 hover `#FAFAFA`,不用斑马纹
- 表单:label 在上(12px/500),输入框 36px 高、6px 圆角,聚焦 navy 边框 + 2px `primary-light` 外圈

## 4. 明确不做(Don't)

- ❌ 渐变按钮、玻璃拟态、彩色大阴影、暗色模式(单一浅色主题,演示场景)
- ❌ 黄色配白字(对比度不够且不像官网)、大面积黄色区块
- ❌ 超过两档的阴影、超过 12px 的卡片圆角、弹跳动画
- ❌ emoji 当图标(统一 lucide-react)
- ❌ 每页多个强调色按钮——"发布"级别的动作一屏只有一个

## 5. 落地方式(Step 6 执行)

1. token 全部写进 `web/src/index.css` 的 CSS 变量 + Tailwind `theme.extend`,组件内禁止出现裸色值(hex 只允许出现在 token 定义处)
2. shadcn/ui 初始化后立即按本文档覆盖其默认变量(`--primary` → navy 等)
3. Google Fonts:Montserrat(600/700)+ Inter(400/500/600)+ JetBrains Mono(400),本地化引入(fontsource),不走 CDN
4. Step 6 完成时产出一个 `/styleguide` 隐藏路由页,平铺展示全部 token 和组件态,作为验收对照
